# BTBlocks changelog

## v1.4 — Christmas Edition + Tile Maze Expansion (in development)

- New Kafelkowy Labirynt: infinite procedural 2D maze based on a photographed stone-wall texture.
- Top-down small character exploring the grout paths.
- Find loot in chests, store in inventory, teleport to trader, sell for coins.
- Buy weapon, trap-disarming equipment, detector and inventory upgrades.
- Bomb/trap risk, guards and a 5-minute blackout event with a yellow flashlight.
- Original Christmas Edition games and other mini-games retained.
- HTML source and Windows build kit prepared privately; **new EXE not yet compiled or published**.
