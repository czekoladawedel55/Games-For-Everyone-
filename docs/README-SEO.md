# BTBlocks search visibility setup

Live site expected at: https://czekoladawedel55.github.io/Games-For-Everyone/

1. Confirm GitHub Pages deployment is enabled: Settings > Pages > Build and deployment > GitHub Actions. The site deployment workflow publishes the docs/ folder.
2. Confirm the URL above loads publicly in an incognito browser. If it shows 404, fix Pages deployment before requesting Google indexing.
3. In Google Search Console (https://search.google.com/search-console/), add a URL prefix property for the exact URL above.
4. Verify site ownership with Google's provided HTML verification tag or file; do not invent a token. Commit the supplied verification file into docs/ if using the file method.
5. Submit sitemap URL: https://czekoladawedel55.github.io/Games-For-Everyone/sitemap.xml.
6. Inspect the homepage URL and request indexing.

No indexing or first-page ranking is guaranteed. Google may require days or weeks. Search appearance is not controllable through metadata alone.
