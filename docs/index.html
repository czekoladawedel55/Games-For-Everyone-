🎮 What is BTBlocks?

BTBlocks is a free indie collection of mini-games for Windows, combining arcade action, puzzles and nostalgic desktop themes. The latest Windows release is BTBlocks v1.7 Enhanced with Orbital Escape, Circuit Master and Pulse Perfect. Earlier versions are available in the archive. The broken initial Android Beta APK was removed. The newer BTBlocks v1.8 Mobile Landscape Beta APK is available for testing with compact UI and clearer controls.

Download the Windows EXE above or explore older BTBlocks releases. This is the official BTBlocks Games for Everyone project website.

🕹️ What's inside?

🎯 Arcade challenges and classic mini-games
🎨 Windows 7, XP, DOS and Mac-inspired themes
🌍 Multiple languages and more updates planned
🛠️ Built with community suggestions

💻 Windows compatibility

Installer target: Windows 7, 8, 8.1, 10 and 11 (64-bit). Some versions and features still require testing. The current Electron-based installer does not support Windows XP or Vista.
