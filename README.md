# 🧱 BTBlocks v1.3 — Games for Everyone

**BTBlocks v1.3** is the current publicly shared version of the game. It is an indie project developed with AI assistance and shaped by community feedback.

## ✨ What's in v1.3?

- A collection of arcade and classic mini-games.
- Theme options inspired by Windows 7, Windows 3.11, Windows XP, DOS and classic Mac OS.
- Language selector: Polish, English, German, Spanish, French and Czech (translation coverage is still in progress).
- Graphics and interface settings, along with experimental multiplayer features.

## 💻 Compatibility

- Windows 7, 8, 8.1, 10 and 11, 64-bit: **intended target** for the Electron 22 installer; compatibility testing is still needed.
- Windows XP / Vista: **not supported by the current EXE**; a separate legacy runtime would be necessary.
- Internet connection may be required by external 3D / multiplayer libraries.
